mods_setting 사용 가이드

Claude Code 화면에 붙이는 개인 mod 두 개 — usage-band(프롬프트 위 띠)와 session-cost(상태 줄).

① 캐릭터 (usage-band)쉬면 졸고, 일하면 걷고, 바쁘면 뛴다. 서브에이전트가 돌면 그 수만큼 새끼가 나온다.
② 한도 (usage-band)5시간·주간 사용률과 초기화 시각. 50% 미만 초록 · 80%↑ 주황 · 95%↑ 빨강.
③ 비용 (session-cost)이번 세션 비용(원화·달러)과 컨텍스트 사용량. 상태 줄이라 색은 넣을 수 없다.

1. mod 가 뭔가요

mod 는 Claude Code 의 화면과 동작을 바꾸는 작은 플러그인입니다. 내 PC 의 Claude Code 가 실행하고, 그림은 화면(표면)마다 쓸 수 있는 요소가 달라서 같은 mod 라도 환경마다 모양이 다릅니다.

“확인 전”은 그 표면이 SVG 를 그릴 수 있다는 것까지만 확인했고, 실제 화면은 보지 못했다는 뜻입니다.

2. 설치

필요한 것 — Claude Code, git, 저장소 호스트()에 닿는 네트워크. 저장소는 공개라 로그인 없이 받아집니다.

① 마켓플레이스 등록 — 저장소 이름과 상관없이 마켓플레이스 이름은 kckang-mods 입니다.

claude plugin marketplace add

② 플러그인 설치 — 사용자 범위로 설치하면 모든 프로젝트·세션에서 보입니다.

claude plugin install usage-band@kckang-mods --scope user
claude plugin install session-cost@kckang-mods --scope user

설치 뒤 Claude Code 입력창에서 /reload-plugins (터미널 claude 는 다시 실행).

업데이트 — 마켓플레이스를 새로 받은 뒤 플러그인을 올리고, Claude Code 를 다시 시작합니다.

claude plugin marketplace update kckang-mods
claude plugin update usage-band@kckang-mods
claude plugin update session-cost@kckang-mods

Claude Code 안에서는 /plugin 메뉴로도 같은 일을 할 수 있습니다. 삭제는 claude plugin uninstall usage-band@kckang-mods.

3. 지금 제공되는 기능

usage-band — 프롬프트 위 띠

  • 캐릭터 자동 결정 — 설치 후 처음 한 번, 지난 여러 세션에서 내가 한 질문과 메모 목차를 읽고 어울리는 동물을 모델이 정합니다(종류 제한 없음). 정하는 동안은 알이 흔들리고, 태어나면 “🐣 ○○ 가 태어났어요 — 이유” 알림. 결과는 이 PC 에 저장돼 세션이 바뀌어도 유지됩니다.
  • 상태에 따라 움직임 — 쉬면 엎드려 졸고(z), 일하면 띠 폭을 오가며 걷고, 최근 20초에 도구 호출이 4번 이상이면 뜁니다. 멋쩍은 말풍선이 4초마다 바뀝니다.
  • 새끼 — 서브에이전트가 돌면 그 수만큼(최대 6) 같은 동물의 새끼가 뛰어다닙니다.
  • 한도 줄 — 5시간·주간 사용률과 초기화 시각(한국 시간). 아직 값이 없으면 5시간 -. 10초마다 갱신.

session-cost — 상태 줄

  • 이번 세션 ₩121,976 ($87.13) · 컨텍스트 77% (775k/1.0M) — /cost 와 같은 세션 합계를 원화로. 30초마다 갱신.
  • 환율 바꾸기: claude plugin configure session-cost@kckang-mods 에서 krwPerUsd(기본 1400).

4. 알아 둘 점

캐릭터를 정할 때(처음 한 번 · reroll · pick 설명) 모델을 한 번 부릅니다. 이때 지난 질문 일부(한 개 200자, 최대 120개)와 메모 목차가 그 요청에 들어갑니다. 파일 내용·도구 결과는 보내지 않습니다.
  • 그림은 부품으로 그리는 작은 SVG 라 실제 일러스트 수준은 아닙니다. “동화책 스타일·높은 디테일” 같은 표현은 담을 부품이 없어 반영되지 않습니다.
  • 데스크톱 그림은 스크립트 없는 화면이라 Three.js·WebGL 같은 3D 는 쓸 수 없습니다.
  • 프롬프트 위 띠는 플러그인 하나만 그립니다 — 같은 자리를 쓰는 다른 mod 와는 함께 못 씁니다.
  • 한도 값은 이 세션의 마지막 응답 기준이라, 다른 창에서 쓴 양은 이 세션이 다음 요청을 보내야 반영됩니다.
